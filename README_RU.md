# Иск-Бот AI MVP — v6: оформление заявления об отмене судебного приказа

Версия сохраняет рабочий чат и подключение к DeepSeek/OpenAI, но улучшает оформление сформированного Word-документа.

## Что изменено в генераторе DOCX

- страница A4; поля: сверху и снизу 2 см, слева 3 см, справа 1,5 см;
- шапка суда, заявителя, взыскателя и номера дела выровнена по правому краю;
- заголовок «ПРОШУ:» выровнен по центру;
- распространённые названия судебных районов Томска автоматически приводятся к родительному падежу, например: «Кировского судебного района города Томска»;
- описательная часть и просительная часть выровнены по ширине;
- Times New Roman, 12 пт, межстрочный интервал 1,5;
- абзацный отступ в основном тексте и аккуратные отступы у нумерованных пунктов;
- заголовок «Приложения (копии):», а у каждого приложения явно указано, что это копия;
- дата размещается перед строкой подписи;
- убрана заглушка с названием отдела ФССП, если подразделение не известно;
- исправляется распространённое написание «о взыскание» на «о взыскании»;
- формы «получал/получала» выбираются по ФИО, когда пол можно надёжно определить по отчеству/фамилии.

## Запуск в Windows PowerShell

Распакуйте архив. Откройте PowerShell в каталоге проекта либо выполните:

```powershell
cd C:\Users\ADMIN\isk_bot_ai_mvp_v5
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

Откройте веб-интерфейс: http://127.0.0.1:8000

Чтобы остановить сервер, нажмите `Ctrl+C` в окне PowerShell.

## Настоящий ИИ

По умолчанию установлен `LLM_PROVIDER=mock`, поэтому приложение запускается без API-ключа. Для реальной модели создайте `.env` в корне проекта на основе `.env.example`.

Для DeepSeek:

```env
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=вставьте_свой_API_ключ
DEEPSEEK_MODEL=deepseek-flash
```

Для OpenAI:

```env
LLM_PROVIDER=openai
OPENAI_API_KEY=вставьте_свой_API_ключ
OPENAI_MODEL=имя_доступной_вам_модели
```

Ключ API не вставляйте в браузерный JavaScript и не отправляйте в переписке. Он должен оставаться только в локальном файле `.env` или на сервере.

## Тесты

Из папки проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты проверяют генерацию DOCX, форматирование и базовый сценарий чата. Юридическое содержание конкретного заявления всё равно необходимо проверить перед подачей в суд.
